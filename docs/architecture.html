Tables and links

jira_requests holds one row per ticket; its AI review columns follow the REVIEW SCHEMA in the scored workbook's "Request Review Design" sheet. The five ref_ tables are TABLE A to E from the same sheet and explain the values in those columns.

All columns

Every table with its columns. PK is the primary key, FK a foreign key, and required means the column is never empty.

jira_requests

5,344 rows

One row per Jira ticket from the scored workbook, including the AI review. The AI review columns follow the REVIEW SCHEMA, and its notes are their column comments.

How the tables could be improved

  • Check that every category, agent and evidence value in a ticket exists in TABLE A, C or D.
  • Only accept the values the review schema allows, such as low, medium or high for confidence.
  • Add a list of allowed sub-types to the sheet, so those can be checked too.
